# Security Policy

TC Pioneer is a cybersecurity education and community project. Security reports affecting the project or its website are welcome.

## Reporting a Vulnerability

Please report vulnerabilities privately rather than publishing sensitive details in a public issue.

Include the affected component, reproduction steps, security impact, and a safe proof of concept when possible.

Do not include real credentials, tokens, personal data, or production secrets.

## Responsible Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing technical details.

## Scope

This policy covers security issues in the source maintained by this repository.
